# Thao tác với CSDL Quản lý bán hàng

Bài tập MySQL dựa trên cơ sở dữ liệu `QuanLyBanHang`.

## Nội dung
- Thêm dữ liệu vào Customer, Order, Product và OrderDetail.
- Hiển thị thông tin các hóa đơn.
- Hiển thị khách hàng đã mua hàng và các sản phẩm đã mua.
- Tìm khách hàng chưa mua sản phẩm.
- Tính giá từng hóa đơn bằng `SUM(odQTY * pPrice)`.

## File
Chạy `QuanLyBanHang_ThaoTac.sql` sau khi đã tạo cấu trúc CSDL `QuanLyBanHang` từ bài trước.
